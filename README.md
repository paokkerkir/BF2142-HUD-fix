# BF2142 Widescreen Fix


## About

A patch for BF2142 which fixes HUD stretching on wide and ultrawide resolutions.

Credits to marekzajac97 who made a [similar HUD fix for BF2](https://github.com/marekzajac97/BF2-HUD-fix), which this patch is based off of.

## Download

Head over to Releases for a download link. Requires BF2142 v1.51 patch & MS VC++ 2019 Redistributable (x86) installed on your system. Works with BF2142 Reclamation.

##Installation

Copy the dinput8.dll and hudfix2142.ini to the main Battlefield 2142 folder.
